# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email the maintainer or use GitHub private vulnerability reporting if it is enabled for the repository. Include:

- affected version or commit
- reproduction steps
- expected and actual behavior
- potential impact

## Secret handling

This repository should not contain API keys, license keys, tokens, private keys, local scan caches, or machine-specific configuration. If you find sensitive data in the repository, report it privately so it can be removed and rotated.
